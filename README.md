# Інтерактивна сторінка: Персональний комп’ютер і його основні складові (§ 3.1, Інформатика 8 клас)

Цей репозиторій містить інтерактивний навчальний модуль для учнів 8 класу, створений для розміщення на **GitHub Pages**.

## 📋 Структура проекту:
- `index.html` — єдиний self-contained файл, який містить:
  - **Теорію** з темами: Інформаційні процеси, Процесор (CPU), Материнська плата, Внутрішня та Зовнішня пам'ять (SSD, HDD, Flash).
  - **Компетентнісне завдання** («Конфігуратор ПК для школяра»).
  - **Інтерактивний тест** з автоматичним оцінюванням за 12-бальною системою.

## 🚀 Як опублікувати на GitHub Pages:
1. Створіть новий публічний репозиторій на GitHub.
2. Розпакуйте цей архів та завантажте файли (`index.html`, `README.md`) у ваш репозиторій.
3. Перейдіть у **Settings** -> **Pages**.
4. У пункті **Source / Branch** оберіть `main` (або `master`) та натисніть **Save**.
5. За кілька секунд сайт буде доступний за адресою:
   `https://<your-username>.github.io/<repository-name>/`
